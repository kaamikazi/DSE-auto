# Broker Integration

`BrokerAdapter` is the future contract. `OfficialBrokerAdapter` is deliberately nonfunctional. No Selenium, terminal clicking, credential scraping, OTP interception, CAPTCHA bypass or unofficial protocol is allowed.

A future adapter requires published official API documentation, broker authorization, authenticated health checks, reconciliation, idempotency, state recovery, sandbox certification and legal review. It must remain downstream of deterministic risk and explicit human approval; AI can never call it.
