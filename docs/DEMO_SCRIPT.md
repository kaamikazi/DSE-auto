# Demo Script

1. Start backend/dashboard and show both permanent safety banners.
2. Open health and demonstrate mock provider offline operation.
3. Import `portfolio-template.csv` after replacing its sample values.
4. Run a buy-and-hold and 20/50 MA backtest; point out next-bar execution and costs.
5. Generate an MA signal and explain the strength score is not probability.
6. Create and approve a small limit proposal; simulate a partial paper fill.
7. Repeat with stale data and show risk rejection.
8. Trigger emergency stop and show all proposals blocked.
9. Display the verified append-only audit chain.
