# Rule Approval Workflow

The 16 assumptions in `dse-paper-rules-v1-draft` each have an independent matrix row. A row shows its draft value, evidence, conflicts, missing evidence, proposed value, effective date, operator, reviewer, independence, status, and immutable decision hash/audit event.

Blanket approval is rejected. An item requires verified evidence or an explicitly approved conservative fallback. A future verified rule-set version may be prepared only after all 16 mandatory rows are approved. The existing draft remains unchanged, assumed, unapproved, and inactive.
