# Weekly Review

After each group of five accepted real-market days run `weekly-report <campaign-id> --output reports\weekly`. The report covers accepted/rejected/missing days, data-quality and infrastructure incidents, strategy behavior, drawdown, turnover, fees, slippage, rejected/missed trades, partial fills, risk interventions, reviewer concerns, unresolved actions, and qualification progress.

JSON and HTML outputs are hash-linked and audited. A partial group does not generate a weekly report. Short samples are operational evidence only and never support a profitability claim.
