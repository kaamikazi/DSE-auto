# Portfolio decision support

Read-only analysis reports allocation, concentration, cash, cost basis, unrealized results, and missing-price warnings. The data model can extend to realized return, dividends, drawdown, volatility, liquidity, sector concentration, DSEX, buy-and-hold, and paper-strategy comparisons once governed inputs exist.

Outputs are labeled `research observation`, `risk warning`, `paper scenario`, or `review required`. They are not imperative instructions, guarantees, or execution authorizations.
