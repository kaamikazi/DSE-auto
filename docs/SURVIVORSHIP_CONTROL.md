# Survivorship control

Research universes are versioned drafts with date-bounded membership. Eligibility considers listing/delisting dates, suspensions, category and symbol history, missing-data periods, liquidity, sector, and available market-cap metadata.

The initial workflow covers GP, ACI, and BRACBANK. Expansion to 30 or more symbols is supported through membership records but is never activated automatically. A historical test must query eligibility on each trading date.
