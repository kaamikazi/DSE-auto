# Public DSE datasets

Supported registrations are Mendeley, Kaggle, DSE Stocks archives, AmarStock, manual broker/exchange files, DSEX series, and future licensed-vendor exports. Registration is metadata, not endorsement. Every raw file is retained by SHA-256 with publisher, reference, coverage, license note, adjustment status, timestamp trust, source trust, operator, review state, and audit linkage.

No source is downloaded automatically. A domain or recognizable publisher name never grants `exchange_verified`; that classification requires reviewed evidence. Deterministic fixtures used in tests are not market evidence.
