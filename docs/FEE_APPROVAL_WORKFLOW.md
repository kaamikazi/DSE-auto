# Fee Approval Workflow

All 12 draft fee components are reviewed separately, including applicability, percentage/flat value, minima/maxima, tax treatment, dates, evidence, confidence, and decision. Missing mandatory components block readiness.

An unresolved optional component may use a documented conservative fallback only after that fallback is individually approved. No fee profile is activated by evidence intake or review. Version `1.0-draft` remains assumed and inactive.
