# Broker questionnaire

- Which CSV/XLSX exports and documented read-only interfaces exist?
- Is a trading or FIX API available to this exact client class?
- How are order status, fills, cancellations, rejections, balances, settlement, market data, and timestamps represented?
- Is there a sandbox; is automation contractually permitted; which client approvals apply?
- What exact effective fee schedule applies?

No retail API access is assumed until the broker confirms it in reviewed evidence.
