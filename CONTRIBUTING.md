# Contributing

External code contributions are not currently accepted while the project owner determines licensing, governance, and review requirements.

Non-sensitive bug reports and documentation observations are welcome. Before opening an issue:

1. Reproduce the problem with mock, deterministic, or sanitized public data.
2. Confirm that paper-only settings remain enabled.
3. Remove local paths, credentials, account identifiers, portfolio values, and private evidence.
4. Describe whether PostgreSQL/Redis integration tests actually ran or were skipped.

Do not propose or submit live broker execution, browser automation, Selenium, passwords, PINs, OTP/CAPTCHA handling, unofficial broker access, AI approval, or TLS-verification bypasses.

Never include private financial information in a public issue or pull request. Security vulnerabilities must follow [SECURITY.md](SECURITY.md).

No public reuse license has been granted. Opening an issue does not grant permission to copy, modify, or redistribute the project.
